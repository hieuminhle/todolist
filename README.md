Das Projekt enthält
• eine Webanwendung, die mittels der vorgestellten Techniken entwickelt (PersistenzSchicht mit JPA, Backend mit Spring, Frontend mit Angular, Security-Mechanismus
mit Apache Shiro)
• die Testierung des Produktes mittels von ALEX

Die Webanwendung sollte eine ToDo-App. Mit der Anwendung sollte man sich registieren
und einloggen/ ausloggen können. Als eine To-Do-Liste sollte es unbedingt möglich sein,
Aufgaben hinzuzufügen, zu ändern oder zu löschen, als erledigt zu markieren, Datum auszuwählen.
Da die Daten in einer digitalen Datenbank gespeichert werden, kann man die ganze App-Funktionalität mit
verschiedenen Geräten benutzen.
